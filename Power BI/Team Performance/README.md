### Report Overview:

This Power BI report is a multi-layered analysis containing three comprehensive pages:

* Top View: Provides a high-level summary of team performance and workload distribution.
* Detailed Analysis: Offers in-depth insights into individual employee performance.
* Insights Page: Highlights key actionable insights derived from the data.

The data used in this report was created with ChatGPT, leveraging advanced data modeling techniques to clean, manipulate, and organize data into fact and dimension tables. 
Data modelling approach ensures optimal performance and smooth functionality, making the report scalable and efficient.
